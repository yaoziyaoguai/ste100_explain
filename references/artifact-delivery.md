# 成品交付与宿主适配

本文件约定选定媒介后的实际交付。适用于临时的解释工具，不要求把演示做成长期产品。

## 选择已有能力

先检查当前宿主实际提供的技能、工具与本地运行时。优先沿用能完成任务的现有能力，不预先安装整套制作环境。

| 交付 | 有相应技能时 | 没有相应技能时 |
| --- | --- | --- |
| 静态关系图 | Mermaid 或现有绘图能力 | 直接生成 Mermaid；需要可下载图片时用可用渲染器生成 SVG/PNG |
| 概念插画 | `imagegen` 或宿主图像工具 | 用可核验的 SVG 示意表达合适的内容；必须使用生成图片时说明能力缺口 |
| 对话内交互 | `visualize` | 制作独立 HTML，并使用宿主可用的浏览器或文件预览 |
| 独立网页解释 | `answer-me-with-html` 或适用的网页制作能力 | 生成自包含 HTML/CSS/JavaScript，无需建立前端工程 |
| 数学与程序动画 | `manim-video` | 检查现有程序绘图和视频编码工具，选择能渲染成片的路径 |
| 非数学讲解视频 | `video-use` 或其他合适的视频工具 | 将场景、字幕和图形动画组合为视频；先验证代表性短片 |

技能名称只是发现入口，不是跨宿主固定 API。读取当前安装版本的说明，遵循宿主的文件位置、预览及权限约定。不能把 Codex 专用的内嵌显示标记当成 Claude Code 通用输出。

## 图解

交付可见的图，而不是“可以画一张图”的建议。让图直接回答结构、顺序、条件或空间关系中的一个问题。

- 连线方向、节点名称和条件来自材料；示意性的省略要说明。
- 示意图可保留可编辑源；科研图、精确计量图使用标准绘图工具。
- 检查文字是否可读、箭头是否接对、图例是否与图中标记一致。没有渲染器时，可交付 Mermaid/SVG 源码，但明确渲染尚未检查。

## 独立 HTML 与交互工具

用户要求 HTML 时，交付能在浏览器打开的完整页面。除非任务另有需要，使用一个自包含文件；按任务需要加入多个视图、案例对比或可操作的模拟，不人为限制为一张卡片。

- 用一句可理解的问题组织页面。标题、正文、图形和控件应有清楚的阅读顺序。
- 每个控件改变一个有意义的状态。动画展示变化；不使用只有装饰作用的播放过程。
- 数据、公式、单位和假设保持一致。教学模拟标明简化条件；缺失实测值时不能填入看似真实的结果。
- 数字、颜色和图形共同表达含义，控件支持键盘。窄窗口中仍能阅读与操作。
- 保留源码；在 Codex 或 Claude Code 中使用各自可用的预览方式，并给出可访问的文件位置。发布到互联网只在用户要求时进行。

验证主要交互、默认状态和关键边界。对照一个可以手算或来自材料的例子检查结果。检查实际页面有无脚本错误、文字遮挡和失效控件；无法检查的部分如实说明。

## 自定义讲解视频与旁白

先确定受众看完后应理解的机制，再编排场景。题材不限于数学：业务流程可展示状态变化，系统机制可展示信息流，概念比较可展示并列案例。

1. 把解释写成可讲述的脚本和分镜，确定图形何时出现、变化或退出。
2. 检查渲染、字体、编码与音频依赖。按已有授权处理必要安装；大型模型下载、外部上传和付费调用遵守已确认范围。
3. 渲染代表性短片，检查中文字形、布局、节奏和图形变化。用户已授权完整制作时，内部短片检查通过后继续。
4. 需要旁白时，将每段声音与对应场景对齐。以实际语音时长安排画面，避免切掉尾音。
5. 输出可播放的视频，检查时长、代表性画面、字幕和涉及的音轨。保留脚本、可编辑动画源与必要资源。

用户要求有声视频时，静音成片或单独讲稿都属于未完成。先解决能解决的部分，再说明具体缺口；不能把静音视频称为配音完成。

### 选择配音方案

- **用户指定 ElevenLabs 等服务**：检查当前可用连接器或官方接口，使用已授权的凭据来源与费用范围。可先用短句验证声音、语言和返回格式，不把密钥写进代码、仓库或输出。
- **用户要求免费或本地**：先检查系统已有语音能力，例如 macOS 的 `say` 及已安装声音；再考虑设备能运行的本地 TTS。中文效果、许可、模型下载量和速度都要核实，不能仅凭名称判断可用。
- **用户没有偏好**：优先试现有本地能力。效果不足时，说明具体问题和合适的替代。需要新增付费授权时，先准备好脚本和可审阅样片，再请求相应授权。

不要硬编码某个付费供应商为必需依赖。无法获得可用声音时，保留已完成的分镜、动画和字幕，并明确有声交付受阻。

## 让用户能够检查结论

把来源、关键假设和适用条件放在可找到的位置。研究和评测类工具可提供查看原始案例或切换假设的操作；不要求所有解释都做成仪表盘。

最终回复指向实际可用产物，说明最关键的结论、做过的检查和仍未验证的部分。源码已写好、页面已运行、视频已渲染和音轨已检查，是不同的完成状态。
